# Мой заработок

Личное приложение учёта доходов, расходов и семейного бюджета.

- `site/` — само приложение (GitHub Pages: https://grach31.github.io/earnings-app/)
- `supabase/setup.sql` — таблицы и правила доступа
- Данные лежат в Supabase, вход по e-mail и паролю. Личные данные (`seed.sql`) в репозиторий не кладём.

## Версия 3.0
- `site/index.html` — новое приложение: карточки «Доход», «Расход», «Банк». Грач видит всё, Ирина (гость) только расходы и банк.
- `site/old/index.html` — прежняя версия 2.3, открывается по ссылке `/old/` (те же данные).
- `supabase/update-3.0.sql` — права в базе: гость читает и пишет только расходы и банк. Выполнить один раз в SQL Editor.

## Версия 3.2
- Новая карточка «Работа» над «Доходом»: плюс открывает шторку (клиника, сумма, техник, процент берётся из настроек), внутри журнал, итоги по клиникам за месяц и за прошлые месяцы. Заработанное нигде не учитывается как доход, 1-го числа счётчик обнуляется. Данные лежат в коллекции `entries`, SQL не нужен.
- «Доходы»: только «ЗП» и «Сдача жилья», суммы вносятся как есть.
